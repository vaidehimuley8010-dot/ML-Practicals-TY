# ML Lab Jupyter Notebooks

This folder contains Jupyter notebooks for the eight machine-learning topics from the handwritten list.

## Notebooks
1. Linear Regression
2. Decision Tree
3. K-Means
4. K-Nearest Neighbors
5. Random Forest
6. SVM
7. Naive Bayes
8. Perceptron

## Before running
1. Install packages: `pip install pandas numpy matplotlib scikit-learn jupyter`
2. Place `diabetes_prediction_dataset.csv` in this same folder.
3. Open Jupyter Notebook/JupyterLab and open a notebook.
4. Run the cells from top to bottom.

The classification notebooks use `diabetes` as the target. Linear Regression predicts the continuous `HbA1c_level`. K-Means is unsupervised and does not use the `diabetes` target to form clusters.
